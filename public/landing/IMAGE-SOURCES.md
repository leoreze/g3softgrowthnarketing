# G3Soft Landing Page imagery

The hero people imagery used by the Landing Page Engine is bundled locally under `public/assets/people/` so the hero does not depend on a third-party image CDN at runtime.

Files currently used:
- `g3-management.webp`
- `g3-restaurant.webp`
- `g3-retail.webp`
- `g3-retail2.jpg`
- `g3-multistore.webp`

These assets were supplied in the project workspace and are used as contextual visual assets. Replace them with G3Soft-approved/licensed photography before commercial publication if required.
