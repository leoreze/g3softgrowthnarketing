# G3Soft Institutional Site — `/g3soft`

The institutional site is integrated into the Growth OS as a first-class public route.

## Route
- `/g3soft`

## Architecture
- `public/g3soft/index.html`
- `public/g3soft/css/styles.css`
- `public/g3soft/js/app.js`
- `public/g3soft/assets/g3soft-logo.png`

## Design
Black / white / G3Soft orange, premium SaaS/editorial layout, responsive, CSS/HTML product mockups, conversion-focused CTA and local form.

## Security
The page is CSP-safe:
- no inline `<style>`;
- no inline `<script>`;
- no inline style attributes;
- no external runtime dependencies.

## Conversion
The lead form is front-end only in this release. Connect it to the existing CRM/API in a subsequent release.
